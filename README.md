# Shell Runner

Sprachlern-Endless-Runner für **Tula’s Island**.

## Repository
Dieses Repository enthält ausschließlich **Shell Runner**. Andere Tula’s-Island-Spiele werden hier nicht bearbeitet.

## Stack
- Standalone HTML/CSS/JavaScript (stabile Übergangsstruktur)
- Node.js Build-/Smoke-Test-Skripte
- Mobile-first
- GitHub Pages

## Entwicklung
```bash
npm ci
npm test
npm run build
```
