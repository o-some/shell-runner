# Shell Runner — Game Design Snapshot

## Kernloop
Der Spieler sieht ein deutsches Wort und steuert Tula per Swipe/Tastatur in eine von drei Spuren. Die drei Tore enthalten mögliche Übersetzungen. Beim Erreichen der Tore wird die gewählte Spur ausgewertet.

## Lernziel
Schnelle Worterkennung und Übersetzungszuordnung im Endless-Runner-Format.

## Systeme
- Punkte
- Combo
- Leben
- Muscheln
- XP
- Geschwindigkeit
- Pause (maximal 2 Nutzungen pro Run)
- Themen-Boss

## Boss
Nach dem regulären Laufabschnitt erscheint ein Boss-Intro. Das Spiel wartet auf den expliziten Start. Im Boss werden Wörter nach Themenwelt statt reiner Übersetzung ausgewählt. Boss-Fehler reduzieren nicht die normalen Leben.

## Steuerung
- Mobile: Swipe links/rechts
- Desktop: Pfeiltasten links/rechts
- Space/Pause-Button: Pause/Weiter
